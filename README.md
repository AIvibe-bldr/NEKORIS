# ねこハウスチェイス

家の中でネコになってネズミを追いかけ、イヌ・人・障害物から逃げる3Dゲームです。
ビルド不要で、`index.html` を静的サーバーで配信すればブラウザで動きます（three.js は `vendor/` に同梱）。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

## あそびかた

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 画面左をドラッグ |
| ジャンプ | Space | ジャンプボタン |
| ダッシュ（スタミナ消費） | Shift | ダッシュボタン長押し |
| 視点 | マウスドラッグ / Q・E | 画面右をドラッグ |

- ネズミを全部つかまえるとステージクリア。ステージが進むとネズミ・イヌ・人が増えて速くなります。
- イヌと人は、壁や家具にさえぎられて見えないネコには気づきません。物かげに隠れてやり過ごせます。
- イヌは見つけると追いかけてきます。テーブルやカウンターなど高い所までは届きません。
- 人は高い所でも手が届きます。ロボット掃除機にぶつかると驚いてしばらく動けません。
- ネズミはベッドやソファの下に逃げ込みます。出てくるまで待ちましょう。

## スマホで遊ぶ

- 縦持ち・横持ちのどちらでも遊べます。
- HTTPSで公開したページをブラウザの「ホーム画面に追加」で登録すると、全画面のアプリとして起動でき、一度開けばオフラインでも遊べます。
- 動きが重い端末では解像度を自動で下げます。
- ダッシュボタンを押したまま指をずらすと、走りながら視点を回せます。

## 構成

- `src/world.js` — 家（壁・家具）、当たり判定、経路探索
- `src/actors.js` — ネコ・イヌ・ネズミ・人のモデルとアニメーション
- `src/main.js` — 操作、AI、ルール、HUD
